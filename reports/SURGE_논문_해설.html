2읽기 전에 알아둘 개념

SURGE는 여러 기존 기법을 조립한 모델이에요. 아래 여섯 가지를 알면 나머지는 따라갈 수 있어요.

순차 추천 (CTR 형태)

입력은 사용자의 클릭 기록 x1, …, xn과 후보 아이템 xt이에요. 출력은 "다음에 xt를 클릭할 확률" ŷ예요. 정답 1/0으로 이진 교차 엔트로피를 최소화해요.

그래프 신경망 (메시지 전달)

각 노드가 이웃 노드의 벡터를 모아(합·평균) 자기 벡터를 고쳐요. 한 번 하면 1-hop, 두 번 하면 2-hop 이웃 정보까지 섞여요.

그래프 어텐션 (GAT)

이웃을 똑같이 더하지 않고, 이웃마다 점수를 매겨 softmax로 정규화한 가중치로 더해요. SURGE의 B단계가 이 구조예요.

그래프 풀링 (DiffPool)

노드 n개를 군집 m개로 줄여요. "노드 i가 군집 k에 속할 확률" 행렬 S (n×m)를 학습하고 STH로 군집 벡터를 만들어요. CNN의 풀링과 같은 역할이에요.

GRU와 AUGRU

GRU는 업데이트 게이트로 "이전 상태를 얼마나 덮어쓸지" 정하는 순환 신경망이에요. AUGRU(DIEN 논문)는 이 게이트에 어텐션 점수를 곱해, 관련 없는 입력은 상태를 거의 못 바꾸게 해요.

정규화에 쓰인 도구

프로베니우스 노름 ‖X‖F: 행렬 원소 제곱합의 제곱근(행렬 간 거리). 엔트로피 H(p) = −Σp log p: 분포가 한 곳에 몰릴수록 0에 가까워요.

3문제의식: 왜 그래프인가

논문은 기존 순차 추천이 풀지 못한 두 가지 문제에서 출발해요.

  1. 암묵적이고 잡음 많은 신호. 클릭·시청 같은 암묵적 피드백은 "좋아요"처럼 선호를 직접 말해주지 않아요. 관심 없는 것도 자주 클릭하고, 그런 기록은 실제 관심을 가리는 잡음이 돼요.
  2. 빠르게 바뀌는 선호. 어느 시점에는 일부 관심만 켜져 있고 나머지는 꺼져 있어요. 예: 월드컵 기간에만 축구 뉴스를 보는 사용자. 잡음을 걸러도 "지금 켜진 관심"을 고르는 일이 남아요.

기존 접근의 세 갈래와 한계

갈래대표 모델어떻게논문이 지적한 한계
규칙·어텐션 가중DIN, FPMC시간 감쇠 규칙이나 후보 아이템 기준 어텐션으로 과거 아이템에 가중치긴 시퀀스에서 핵심 부분에 집중하지 못함. 가장 큰 어텐션이 먼 과거의 엉뚱한 아이템에 갈 수 있음
순환 신경망GRU4REC, DIEN시퀀스를 RNN으로 요약해 마지막 상태를 사용자 표현으로단기 병목. 긴 의존성을 잊고 최근 기록 위주. 잡음이 다음 단계 입력으로 전파됨
장·단기 분리SLi-Rec장기 관심과 단기 관심을 따로 모델링해 합침장·단기를 나누고 합치는 기준이 모호함. 긴 시퀀스(Kuaishou)에서는 GRU4REC보다도 못함

SURGE의 답은 "시간 순서 대신 유사도로 다시 연결하자"예요. 그래프로 만들면 t1과 t8의 신발이 시간상 멀어도 바로 이웃이 돼요. 자주 반복된 관심은 노드 차수가 높은 촘촘한 덩어리가 되고, 잡음은 외톨이 노드가 돼요. 논문은 이것을 "이웃은 비슷하고, 촘촘한 부분 그래프가 핵심 관심이다"라는 사전 가정(prior)으로 둬요.

세션 기반 추천의 그래프 모델(SR-GNN 등)과는 그래프를 만드는 기준이 달라요. 그쪽은 "A 다음에 B를 클릭했다"는 전이로 엣지를 만들어 짧은 세션 안의 반복 행동을 잡아요. 긴 기간에는 같은 행동이 잘 반복되지 않아서, SURGE는 전이 대신 임베딩 유사도로 엣지를 만들어요. 논문은 아이템 동시 출현(co-occurrence)도 사용자마다 연결된 그래프를 만들기에는 너무 희소하다고 봤어요.

5A. 관심 그래프 만들기 (3.1절)

5-1. 노드와 엣지

사용자 기록의 아이템 하나가 노드 하나예요(노드 수 n = 기록 길이). 각 노드는 아이템 임베딩 hi ∈ ℝd를 가져요. 무방향 그래프의 인접 행렬 A ∈ ℝn×n를 학습하는 것이 목표예요. 그래서 그래프 만들기 문제를 "노드 유사도를 재는 함수를 학습하는 문제(metric learning)"로 바꿔요. 이 함수는 추천 손실과 함께 학습돼요.

5-2. 학습형 유사도: 가중 코사인 + 멀티헤드

Mij = cos( w ⊙ hi , w ⊙ hj )(1)
Mδij = cos( wδ ⊙ hi , wδ ⊙ hj ),   Mij = (1/φ) Σδ=1φ Mδij(2)
  • w는 학습되는 가중치 벡터예요. 임베딩의 차원마다 "이 차원을 유사도에서 얼마나 중요하게 볼지"를 정해요. ⊙는 원소별 곱이에요.
  • 헤드 φ개가 서로 다른 wδ로 각자 유사도 행렬을 만들고 평균을 내요. 헤드마다 다른 관점(예: 가격대, 용도)을 볼 수 있고 학습이 안정돼요.
  • 커널 방식(코사인·유클리드·마할라노비스)과 어텐션 방식 가운데, 표현력과 계산량의 균형 때문에 가중 코사인을 골랐다고 해요.
  • 임베딩이 학습되면서 그래프 구조도 계속 바뀌어요. 처음 보는 아이템에도 바로 그래프를 만들 수 있어요(귀납적 학습 가능).

5-3. 희소화: 전체 그래프 기준 상대 순위 (ε-sparseness)

코사인 값은 [−1, 1]이라 그대로 쓰면 모든 노드가 연결된 완전 그래프가 돼요. 계산이 비싸고, 중요하지 않은 엣지가 잡음이 돼요. 그래서 가장 강한 연결만 남겨요.

Aij = 1  if  Mij ≥ Rankεn²(M),   otherwise 0(3)

Rankεn²(M)는 행렬 M의 원소 n²개 중 εn²번째로 큰 값이에요. 즉 전체 원소 중 상위 ε 비율만 1로 만들어요. 아래에서 ε를 직접 바꿔 보세요.

5-4. 왜 "전체 상대 순위"인가: 세 가지 희소화 전략 비교

논문은 다른 두 방식을 명시적으로 비교하고 기각해요. 아래 세 그림은 같은 10개 아이템에 각 방식을 적용한 결과예요.

전략예논문이 든 문제
(가) 전체 절대 임계값IDGL [5]임베딩이 학습되며 유사도 분포가 바뀌어요. 임계값을 잘못 잡으면 그래프가 아예 안 생기거나 완전 그래프가 돼요.
(나) 노드별 상대 순위 (kNN)[4], [19]모든 노드 차수가 같아져요. 균일한 희소 분포를 강요해서, 뒤의 GCN이 "어디가 촘촘하고 어디가 성긴지"라는 구조 정보를 못 써요.
(다) 전체 상대 순위 (SURGE)식 (3)하이퍼파라미터 ε에 덜 민감하고, 그래프의 희소 분포를 망가뜨리지 않아요.

리뷰어 메모 식 (3)은 0/1 값만 내는 계단 함수라 미분이 0이에요. 그런데 본문은 w가 추천 손실과 함께 학습된다고 해요. 그래디언트가 w까지 어떻게 가는지(예: 마스크 위치의 Mij 값을 가중치로 쓰는지)는 본문에 없어요. 재현할 때는 공식 코드를 확인해야 해요.

6B. 관심 융합 그래프 합성곱 (3.2절)

그래프가 생기면 이웃 정보를 모아 각 노드 벡터를 고쳐요. 목표는 약한 신호를 강한 신호로 모으는 것이에요. 같은 관심의 클릭 여러 개가 서로 정보를 주고받으면 그 관심이 또렷해지고, 외톨이 잡음은 받는 정보가 적어 묻혀요.

6-1. 업데이트 식

h′i = σ( Wa · Aggregate( Eij · hj | j ∈ Ni ) + hi )(4)
h′i = ∥δ=1φ σ( Waδ · Aggregate( Eδij · hj | j ∈ Ni ) + hi )(5)
  • Ni는 노드 i의 이웃이고 자기 자신도 포함해요(self-loop). Aggregate는 합(sum)을 썼어요.
  • + hi는 잔차 연결이에요. 식 (5)는 GAT처럼 φ개 헤드 결과를 이어 붙여요(∥). 그래서 출력 차원은 φd′이에요.
  • 핵심은 이웃 가중치 Eij를 어떻게 정하느냐예요. 두 가지 점수를 더해요.

6-2. 두 가지 어텐션

αi = Attentionc( Wchi ∥ hic ∥ Wchi ⊙ hic )(6)
βj = Attentionq( Wqhj ∥ ht ∥ Wqhj ⊙ ht )(7)
Eij = softmaxj( αi + βj ) = exp(αi + βj) / Σk∈Ni exp(αi + βk)(8)
  • 군집 인식 αi: 타깃 노드 i의 k-hop 이웃을 하나의 군집으로 보고, 그 평균 hic와 hi를 비교해요. 입력은 "자기 ∥ 군집 평균 ∥ 둘의 원소곱"이고, 2층 피드포워드망(LeakyReLU)이 점수를 내요.
  • 질의 인식 βj: 같은 구조로 소스 노드 hj와 후보 아이템 ht를 비교해요. 관련 있는 행동만 예측에 쓰이도록, 관련 없는 정보는 모으는 과정에서 버려요. DIN의 "후보 기준 어텐션"을 그래프로 옮긴 셈이에요.
  • 두 점수를 더한 뒤(additive attention) 이웃에 대해 softmax를 해요. 논문 설명으로는 self-loop에서 α가 "타깃이 얼마나 받을지", β가 "소스가 얼마나 보낼지"를 조절해요.
  • β에 softmax를 한 값 γi는 "노드 i의 중요도"로 C단계(풀링·readout)에서 다시 쓰여요.

리뷰어 메모 식 (8)을 쓰인 그대로 계산하면 αi는 결과에 영향이 없어요. softmax는 j에 대해 정규화하는데, αi는 모든 j에 같은 값으로 더해지므로 분자와 분모에서 exp(αi)가 약분돼요(위 표). 그런데 Table 4에서는 군집 인식을 빼면 성능이 떨어져요(Taobao AUC 0.8906 → 0.8764). 그러니 실제 구현은 식 (8)과 다를 가능성이 커요. 예를 들어 노드 전체에 대해 정규화하거나, α를 다른 곳에 곱해 쓸 수 있어요. 이 구조를 재사용하려면 공식 코드를 꼭 확인해야 해요.

7C. 관심 추출 그래프 풀링 (3.3절)

B단계로 관심이 또렷해졌지만 노드는 여전히 n개예요. C단계는 CNN의 다운샘플링처럼 그래프를 m개 군집 노드로 줄여요(m < n). 느슨한 관심이 촘촘한 관심으로 바뀌고, 관심의 분포는 유지돼요.

7-1. 소프트 군집 배정과 풀링

Si: = softmax( Wp · Aggregate( Aij · h′j | j ∈ Ni ) )(11)
{ h*1, …, h*m } = ST { h′1, …, h′n },   { γ*1, …, γ*m } = ST { γ1, …, γn },   A* = STAS(9)(10)
  • S ∈ ℝn×m의 행 하나는 "노드 하나가 각 군집에 속할 확률"이에요(행 합 1). DiffPool처럼 GNN 한 층으로 만들어요. Wp의 출력 차원이 군집 수 m이에요.
  • 군집 벡터 h*는 소속 확률로 가중합한 노드 벡터이고, 군집 점수 γ*도 같은 방식으로 모아요.
  • A* = STAS는 줄어든 그래프의 인접 행렬로, 군집 사이의 연결을 보존해요. 같은 연산을 반복하면 여러 층으로 계층적인 압축도 할 수 있어요.

7-2. 정규화 세 가지: 왜 필요한가

논문은 S를 추천 손실의 그래디언트만으로 학습하기 어렵다고 봐요. 비볼록 문제라 학습 초기에 나쁜 국소해에 빠지기 쉽고, 풀링 뒤에는 군집의 시간 순서가 보장되지 않아요. 그래서 정규화 항 세 개를 손실에 더해요.

LM = ‖ A, SST ‖F(12) 같은 군집 정규화
LA = (1/n) Σi=1n H( Si: )(13) 단일 소속 정규화
LP = ‖ Pn S, Pm ‖2,   Pn = (1, 2, …, n),  Pm = (1, 2, …, m)(14) 상대 위치 정규화
정규화뜻직관
같은 군집 (LM)(SST)ij = Σk SikSjk는 "노드 i와 j가 같은 군집에 들어갈 확률"이에요. 이것을 인접 행렬 A에 맞춰요.강하게 연결된 두 노드는 같은 군집으로, 연결 없는 노드는 다른 군집으로
단일 소속 (LA)각 행 Si:의 엔트로피를 줄여요. 최적은 한 군집에만 1인 원-핫(엔트로피 0)이에요.노드마다 소속 군집이 분명해져서 군집의 의미가 또렷해짐
상대 위치 (LP)S의 큰 값들이 주대각선 근처에 오게 해요. 군집 순서를 바꾸는 인덱스 교환은 미분할 수 없으니 정규화로 대신해요.시퀀스 앞쪽 노드는 앞쪽 군집으로 → 풀링 뒤에도 관심의 시간 순서 유지

7-3. 직접 보기: 정규화가 S를 어떻게 바꾸나

그림 3의 그래프(ε = 0.30, self-loop 포함)를 A로 두고, 10개 노드를 m = 3개 군집으로 묶는 S의 네 단계를 비교해요. S 값은 설명을 위해 만든 예시예요. 오른쪽 수치는 이 페이지가 실제로 계산해요.

리뷰어 메모 식 (14)를 문자 그대로 계산하면 (PnS)k = Σi i·Sik는 위치의 합이라, 1…m 범위인 Pm와 척도가 달라요. 열 정규화(평균 위치)나 n→m 척도 변환을 했는지는 본문에 없어요. 그래서 그림 6에서는 LP 대신 "군집별 평균 시점"과 그 순서를 보여 줘요.

7-4. 그래프 readout

hg = Readout( { γi · h′i , i ∈ G } )   (Readout = sum)(15)

풀링과 별개로, 풀링 전 그래프의 모든 노드를 중요도 γ로 가중합해 그래프 전체 표현 hg를 만들어요. 순서에 무관한 합을 써서 순열 불변성을 지켜요. 이 벡터는 예측층에 같이 들어가, 풀링 층이 각 군집 정보를 더 잘 뽑도록 도와요. Table 4에서 readout을 빼면 Taobao AUC가 0.8906 → 0.8578로 꽤 떨어져요.

8D. 예측층과 손실 함수 (3.4절)

상대 위치 정규화 덕분에 군집 벡터 h*1, …, h*m는 시간 순서를 가진 짧은 관심 시퀀스로 볼 수 있어요("pooled graph를 flatten"). 여기에는 어떤 순차 모델이든 쓸 수 있는데, 논문은 AUGRU를 골랐어요.

hs = AUGRU( { h*1, …, h*m } )(16)

AUGRU (DIEN 논문의 정의): ut = σ(Wuh*t + Uust−1 + bu),  ũt = γ*t · ut,  st = (1 − ũt) ⊙ st−1 + ũt ⊙ s̃t. 여기서 s는 GRU 은닉 상태, s̃는 후보 상태예요.

ŷ = Predict( hs ∥ hg ∥ ht ∥ hg ⊙ ht )(17)
L = −(1/|O|) Σo∈O ( yo log ŷo + (1 − yo) log(1 − ŷo) ) + λ‖Θ‖²   + λMLM + λALA + λPLP(18) + 3.3.2절
  • Predict는 은닉층 [100, 64]의 2층 피드포워드망이에요. 모든 비교 모델이 같은 예측망을 공유해서 공정하게 비교했어요.
  • 손실은 CTR 예측의 표준인 음의 로그우도(이진 교차 엔트로피)에 L2 정규화를 더한 것이에요. 3.3.2절의 정규화 세 개도 최종 목적 함수에 더해요. 계수는 {1e−7, 1e−5, 1e−3} 중에서 골랐어요.

12피어리뷰: 장점과 한계

방법론의 장점

  • 장점 시퀀스를 그래프로 다시 읽는 관점. 시간상 떨어진 같은 관심을 바로 연결해서 RNN의 단기 병목을 구조적으로 피해요. 길이가 길수록 이득이 커지는 결과(Figure 2)가 이 주장과 맞아요.
  • 장점 희소화 설계의 근거가 분명해요. 절대 임계값과 노드별 kNN의 실패 방식을 짚고 전체 상대 순위를 골랐어요. 학습 중 유사도 분포가 움직이는 상황에서도 그래프 밀도가 안정돼요.
  • 장점 군집에 대한 요구를 미분 가능한 손실로 표현했어요. 같은 군집·단일 소속·시간 순서라는 세 가지 요구를 각각 LM, LA, LP로 만들어 추천 손실과 함께 학습해요. 다른 문제에 떼어 가기 쉬운 부품이에요.
  • 장점 정확도와 효율을 같이 잡았어요. 풀링으로 순환 단계가 줄어 학습이 오히려 빨라졌어요(Taobao 14.96분, 최단). 풀링 시퀀스는 어떤 순차 모델에도 붙일 수 있어요(Figure 4).
  • 장점 공정한 비교 장치. 모든 모델이 같은 프레임워크, 같은 예측망 [100, 64], 같은 손실을 써요. 산업 데이터(Kuaishou, 1,495만 인스턴스)로도 검증했어요.

방법론의 한계

  • 한계 식과 구현의 불일치 가능성. 식 (8)에서 αi는 softmax에서 약분되는데(6-3절), 제거 실험은 군집 인식이 효과가 있다고 해요. 식 (3)의 0/1 마스크로 w가 어떻게 학습되는지, 식 (14)의 척도도 설명이 없어요. 재현성을 떨어뜨리는 부분이에요.
  • 한계 평가 프로토콜이 불충분하게 쓰였어요. 음성 샘플을 몇 개, 어떻게 뽑았는지 적혀 있지 않아요. Kuaishou MRR 0.93, NDCG@2 0.95 같은 높은 값은 후보 목록이 아주 짧다는 뜻이라, 실제 전체 랭킹 성능과는 거리가 있을 수 있어요.
  • 한계 기준 모델 구성. 같은 시기의 대표적 셀프 어텐션 순차 모델(SASRec, BERT4Rec)이 빠졌어요. SASRec은 참고문헌 [13]에 있는데도 비교하지 않았어요. 세션 그래프 모델(SR-GNN 등)도 "과제가 다르다"는 이유로 빠졌어요.
  • 한계 "동적" 풀링인데 군집 수 m은 고정. m은 데이터셋 단위로 격자 탐색한 하이퍼파라미터이고, 사용자마다 관심 수가 달라도 같은 m을 써요. 최종 선택된 m과 ε 값, ε 민감도 분석도 보고되지 않았어요.
  • 한계 통계적 신뢰도. 시드별 반복이나 분산이 없어요. 제거 실험에는 유의성 표시가 없고, MRR 값 두 개가 비정상이에요(11-4절).
  • 한계 해석 가능성 주장의 근거 부족. 정규화가 "더 해석 가능한 군집 배정"을 준다고 했지만, 실제 군집이 무엇을 뜻하는지 보여 주는 사례 분석이나 시각화가 없어요.
  • 한계 사전 가정의 위험. "촘촘한 부분 그래프 = 핵심 관심"은 가정이에요. 인기 아이템을 반복 노출로 클릭한 경우에도 촘촘한 군집이 생길 수 있어요. 계산량도 사용자마다 O(n²)라 매우 긴 기록에는 그대로 쓰기 어려워요.

결과의 의미

이 논문의 가장 큰 메시지는 "긴 기록의 잡음 문제는 모델을 더 깊게 쌓기보다 입력을 군집 단위로 압축해서 푸는 편이 낫다"예요. Figure 4가 이를 뒷받침해요. 예측층을 무엇으로 바꿔도 풀링된 시퀀스를 쓰면 좋아졌으니, 성능의 원천은 군집 압축이에요. 또 군집 품질을 추천 손실만으로 학습하기 어렵고 구조적 정규화(같은 군집·단일 소속·순서)가 필요하다는 점도 보여 줘요. 다만 이 정규화의 AUC 기여는 작았어요(−0.0091). 정규화의 진짜 가치는 성능보다 군집의 의미를 고정하는 데 있다고 읽는 편이 맞아요.

후속 연구로 저자들은 온라인 A/B 테스트와, 클릭·찜 같은 여러 행동 유형을 함께 쓰는 확장을 계획했어요.

13내 연구(뉴스 SID)에 접목할 아이디어

현재 연구는 EB-NeRD 뉴스 기사를 RQ-VAE로 SID(c1 카테고리 · c2 사건 · c3 세부)로 만들고 Transformer로 추천하는 구조예요. SURGE에서 가져올 수 있는 부품은 세 가지예요.

① LM + LA를 c2의 사건 일관성 손실로

c2 코드북 128개를 SURGE의 군집 m개로 보면, 잔차 r1과 코드 사이 거리의 softmax가 곧 소프트 배정 S예요. 같은 사건 기사 쌍에 SST → 1을, 엔트로피로 원-핫을 요구하면 "같은 사건 = 같은 c2"를 학습 중에 직접 강제할 수 있어요. 보류해 둔 B안(사건 일관성 손실)의 정식 형태예요.

② 사건 그래프를 전체 상대 순위로

지금 사건은 IDF 가중 Jaccard ≥ 0.3이라는 절대 임계값이라, Train 기사의 약 91%가 혼자인 사건이에요. 5-4절의 논리대로, 72시간 창 안에서 Jaccard와 E5 코사인을 섞은 유사도로 상위 ε 비율의 엣지만 남기면 임계값 민감도가 줄고 모든 기사에 이웃이 생겨요.

③ Transformer 입력을 (c1, c2) 군집으로 풀링

SID 자체가 이미 군집 배정이에요. 사용자 클릭 기록을 같은 (c1, c2)끼리 묶어 관심 노드로 줄이고, 마지막 클릭 시각으로 순서를 유지하고(LP의 역할), 후보 기사 기준 어텐션(β의 역할)을 주면 SURGE의 C·D단계를 학습 없이 재현할 수 있어요. c2가 사건을 잘 담는지를 추천 성능으로 확인하는 실험도 돼요.

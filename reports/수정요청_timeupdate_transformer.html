유사도 식을 IDF 가중 Jaccard로

필수 · 1순위
지금

문제
0.3은 Train 사건을 만들 때 쓴 Jaccard 기준이에요. 코사인은 값이 더 크게 나와서 훨씬 쉽게 통과해요.
예: 기사 {A}, 사건 {A~I} 9개 → 코사인 0.33(통과), Jaccard 0.11(탈락)
이렇게
전처리 src/build_train.py의 _idf_weighted_jaccard와 같은 식으로 바꿔요. weight_sq, norms_sq는 지우고, 개체별 사건 색인(inverted)은 그대로 써서 겹치는 사건만 계산해요. 
idf_map = {norm(e): float(v) for e, v in zip(idf_df["entity"], idf_df["idf"])}
unseen_idf = math.log(N + 1) + 1.0          # N = IDF 계산에 쓴 Train 기사 수 (전처리에서 받기)

def idf_jaccard(a, b):
    inter = a & b
    if not a or not b or not inter:
        return 0.0
    num = sum(idf_map.get(e, unseen_idf) for e in inter)
    den = sum(idf_map.get(e, unseen_idf) for e in a | b)
    return num / den

# 반복문 안: 시간 창 안 + 개체가 겹치는 사건만
cands = {j for t in article_entities for j in inverted.get(t, ()) if eligible[j]}
scores = {j: idf_jaccard(article_entities, entity_sets[j]) for j in cands}

물려주는 사건 C2를 r1 평균으로 계산

보류 · 교수님 확인 후
어디
학습이 아니라 SID 생성 단계예요. compute_event_c2_from_mean_h()(467번 줄)가 Train 사건마다 대표 C2를 정하고, 이 값이 Validation 기사에 물려줄 C2가 돼요(869, 936번 줄). Train 기사 자신의 C2와는 상관없어요.
지금
509번 줄 h = model.encode(x)의 h 평균을 558번 줄에서 그대로 Q2에 넣어요. 그런데 Q2는 r1 = h − Q1[카테고리] 공간에서 학습됐어요.
예시
Q1[스포츠] = (10, 0), Q2 코드 A = (11, 1), 코드 B = (1, 1)
hr1 = h − Q1C2
Train 기사 1(11, 1)(1, 1)B
Train 기사 2(11, 2)(1, 2)B
사건 C2 · 지금 (h 평균)(11, 1.5)A
사건 C2 · 수정 (r1 평균)(1, 1.5)B
지금 방식이면 같은 사건인데 Train 기사는 B, Validation 기사는 A를 받아요.
이렇게
z(E)는 코사인 매칭에도 쓰이니까 h 평균(코사인용)은 그대로 두고, r1 평균(사건 C2용)을 따로 하나 더 계산해요.

r1 = model.get_c2_residual(x, category_ids)             # 사건 C2용 (추가)
# 사건별로 h 합과 r1 합을 따로 누적
# 558번 줄: Q2에는 r1 평균을 넣기
q2_out = model.quantizer_2(x=r1_mean_events, temperature=1.0)

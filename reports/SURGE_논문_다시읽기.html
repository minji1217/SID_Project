5A. 관심 그래프 만들기 (3.1)

사용자 한 명의 기록마다 무방향 그래프를 하나씩 만들어요. 노드 = 기록의 아이템 하나(n개), 각 노드는 임베딩 hi ∈ ℝd를 가져요. 목표는 인접 행렬 A를 정하는 거예요.

왜 그래프인가. 그래프로 보면 핵심 관심과 주변 관심을 가르기 쉬워요. 핵심 관심 노드는 비슷한 노드와 많이 이어져 차수(degree)가 높고, 비슷한 관심이 자주 나오면 크고 촘촘한 부분 그래프가 돼요. "이웃은 비슷하다, 촘촘한 부분 그래프가 핵심 관심이다"를 사전 가정(prior)으로 둬요.

왜 동시 출현이 아니라 유사도 학습인가. 두 아이템이 같이 나온 횟수로 잇는 것도 합리적이지만, 너무 희소해서 사용자마다 연결된 그래프가 잘 안 만들어져요. 그래서 그래프 만들기를 노드 유사도 척도 학습(metric learning) 문제로 바꾸고, 추천 과제와 함께 학습해요. 함수라서 테스트 때 새 아이템에도 바로 쓸 수 있다고 해요(귀납적 학습).

Mij = cos( w ⊙ hi, w ⊙ hj )식 (1) 가중 코사인, ⊙ = 원소별 곱, w = 학습되는 가중치 벡터
Mδij = cos( wδ ⊙ hi, wδ ⊙ hj ),  Mij = (1/φ) Σδ Mδij식 (2) 헤드 φ개의 평균
Aij = 1 (Mij ≥ Rankεn²(M)),  0 (그 외)식 (3) 전체에서 상위 ε 비율만 남김
그림 3. 예시 기록 8개(스포츠 2, 정치 4, 요리 1, 잡음 1)로 실제로 계산한 유사도 행렬과 그래프. ε = 0.34이면 64칸 중 상위 21칸(대각선 8칸 포함)이 1이 돼서, 정치 4개는 서로 다 이어진 촘촘한 덩어리가 되고 요리와 잡음은 외톨이가 돼요. 임베딩은 설명용으로 정한 3차원 값이고 w = 1로 뒀어요.

희소화를 왜 "전체 상대 순위"로 하나

코사인은 −1~1이라 그대로 쓰면 모든 쌍이 이어진 완전 그래프가 돼요. 계산이 무겁고, 중요하지 않은 선(잡음)이 섞이고, 뒤의 합성곱이 중요한 부분에 집중하지 못해요. 그래서 일부만 남기는데, 남기는 방식이 셋 있어요.

방식규칙문제
전체 절대 임계값M ≥ 0.9 이면 연결임베딩이 학습되며 값의 분포가 움직이면 선이 하나도 없거나 모두 이어져요
노드별 상위 k개노드마다 가장 비슷한 k개모든 노드의 차수가 같아져서 "어디가 촘촘한지" 정보가 사라져요
전체 상대 순위 (SURGE)n² 칸 전체에서 상위 ε 비율비율만 정하니 분포가 움직여도 밀도가 일정하고, 촘촘한 곳과 성긴 곳의 차이가 남아요

6B. 관심 융합: 군집·질의 인식 그래프 어텐션 합성곱 (3.2)

그래프가 생기면 핵심 관심은 큰 덩어리, 주변 관심은 작은 덩어리가 돼요. 이제 이웃끼리 정보를 모아(aggregate) 약한 신호를 강한 신호로 만들어요. 각 노드 i는 이웃 j에게서 비율 Eij만큼 받아 자기 벡터를 고쳐요.

h′i = σ( Wa · Aggregate( Eij · hj | j ∈ Ni ) + hi )식 (4) Aggregate = 합, + h_i = 잔차 연결
h′i = ∥δ=1..φ σ( Waδ · Aggregate( Eδij · hj ) + hi )식 (5) 헤드 φ개를 이어 붙임 → φd′ 차원

섞는 비율 Eij는 두 가지를 함께 봐요.

αi: 군집 인식 (cluster-aware)

받는 노드 i를 덩어리의 중심(medoid) 후보로 보고, i의 k-hop 이웃 평균 hic와 비교해 "i가 덩어리 중심인가"를 점수로 내요.

αi = Attentionc( Wchi ∥ hic ∥ Wchi ⊙ hic ) (6)

βj: 질의 인식 (query-aware)

보내는 노드 j가 후보 아이템 ht와 얼마나 관련 있는지 점수로 내요. 관련 있는 정보만 남기고 관련 없는 정보는 버리려는 거예요.

βj = Attentionq( Wqhj ∥ ht ∥ Wqhj ⊙ ht ) (7)

Eij = softmaxj( αi + βj ) = exp(αi + βj) / Σk∈Ni exp(αi + βk)식 (8) 덧셈형 어텐션, N_i 는 i 자신 포함
그림 4. 정치 노드 5번이 이웃(2·7·8번)과 자기 자신에게서 정보를 받는 장면. 섞는 비율 E는 받는 쪽의 "중심다움" α와 보내는 쪽의 "후보 관련도" β를 더해 softmax로 정해요. 두 Attention은 모두 2층 FFN(LeakyReLU)이에요. 화살표 굵기는 설명용이에요.

논문 설명: αi는 받는 노드가 정보를 얼마나 받을지, βj는 보내는 노드가 얼마나 보낼지를 정해요. 그 결과 핵심 관심은 강해지고 잡음은 약해져요. 후보가 β로 들어가므로 이 단계부터 결과가 후보마다 달라요.

7C. 관심 추출: 그래프 풀링 (3.3)

융합으로 신호를 키운 뒤, CNN의 풀링처럼 그래프를 줄여서 느슨한 관심을 촘촘한 관심으로 바꿔요. 이때 관심의 분포는 유지해요.

배정표 S와 덩어리 값

Si: = softmax( Wp · Aggregate( Aij · h′j | j ∈ Ni ) )식 (11) S ∈ ℝ^(n×m), W_p 출력 = 덩어리 수 m
{h*1, …, h*m} = Sᵀ {h′1, …, h′n},  {γ*1, …, γ*m} = Sᵀ {γ1, …, γn}식 (9)(10) γ_i = β_i 의 softmax
그림 5. S의 행은 노드, 열은 덩어리이고, 한 행은 그 노드가 덩어리마다 속하는 비율(합 1)이에요. Sᵀ를 곱하면 노드 값이 덩어리 값으로 모여요: 벡터 h′를 모으면 덩어리 값 h*, 노드 중요도 γ를 모으면 덩어리 중요도 γ*. SᵀAS는 덩어리끼리의 연결이라 같은 계산을 반복하면 여러 층으로 압축할 수 있어요. 숫자는 설명용이에요.

배정 정규화 세 개 (3.3.2)

추천 손실의 기울기만으로는 S를 학습시키기 어렵대요. 비볼록 최적화라 초반에 나쁜 국소해에 빠지기 쉽고, 풀링 뒤 덩어리 사이의 시간 순서도 보장되지 않아요. 그래서 벌점 셋을 손실에 더해요.

LM = ‖A − SSᵀ‖F,  LA = (1/n) Σi H(Si:),  LP = ‖PnS − Pm‖2식 (12)(13)(14), P_n = (1…n), P_m = (1…m)
그림 6. 세 벌점이 S에 바라는 모양. LM: 연결 강도 A와 "같은 덩어리일 확률" SSᵀ가 비슷하게. LA: 각 행이 원-핫에 가깝게(엔트로피 0). LP: 앞쪽 노드가 앞쪽 덩어리에 배정되도록 S의 0 아닌 칸을 주대각선 가까이. 덩어리 순서를 직접 바꾸는 건 미분이 안 돼서 벌점으로 대신해요.

그래프 읽기 (3.3.3)

hg = Readout( { γi · h′i, i ∈ G } )식 (15) Readout = 합, 풀링 전 그래프 전체

압축된 그래프와 별도로, 풀링 전 노드 전체를 중요도 γi로 가중합해 그래프 수준 요약 hg를 만들어 예측 층에 넣어요. 노드마다의 중요도를 제약해서 풀링 층이 덩어리 정보를 더 잘 뽑게 하려는 목적이에요.

8D. 예측과 손실 (3.4)

관심은 외부 환경과 내부 인식의 영향으로 계속 변해요(예: 한동안 여러 스포츠, 다른 때는 책). 그래서 덩어리들의 시간 관계를 반영해야 해요. LP 덕분에 덩어리 순서가 시간 순서를 따르므로, 풀링된 그래프를 펴면(flatten) 관심 신호가 강화된 짧은 시퀀스가 돼요. 이 시퀀스에는 어떤 순차 모델을 써도 되고, 논문은 AUGRU를 써요.

hs = AUGRU( h*1, h*2, …, h*m )식 (16) 갱신 문 u 의 모든 차원에 γ*_k 를 곱함
ŷ = Predict( hs ∥ hg ∥ ht ∥ hg ⊙ ht )식 (17) 2층 FFN
L = −(1/|O|) Σo [ yo log ŷo + (1−yo) log(1−ŷo) ] + λ‖Θ‖²식 (18) + 벌점 L_M, L_A, L_P
그림 7. 덩어리 m개를 시간순으로 AUGRU에 넣으면, 중요도 γ*가 작은 덩어리는 기억을 거의 바꾸지 못해서 관심 표류(interest drifting)의 방해가 줄어요. 마지막 상태 hs, 그래프 요약 hg, 후보 ht, hg⊙ht를 이어 붙여 MLP로 클릭 확률 ŷ를 내요.

11관련 연구와 결론 (5–6)

순차 추천

마르코프 체인(FPMC) → RNN·어텐션 기반 딥러닝. 대부분 최근 행동에 집중해요. 장·단기를 합친 연구(SLi-Rec 등)도 있지만, 관심을 장기·단기로 거칠게 나누는 건 합리적이지 않다고 봐요. SURGE의 관점은 "행동은 약한 선호 신호이고, 어떤 선호는 특정 시점에 꺼져 있다"예요.

추천을 위한 GNN

PinSage, NGCF, LightGCN 등이 사용자-아이템 그래프에서 성과를 냈어요. 세션 추천의 GNN은 짧은 세션의 반복 전이를 잡는 것이라 순차 추천과 달라요. SURGE는 그래프 합성곱으로 약한 신호를 모으고, 그래프 풀링으로 긴 기록에서 활성화된 핵심 선호를 뽑는다는 점이 다르다고 해요.

결론과 향후 과제

느슨한 시퀀스를 촘촘한 관심 그래프로 바꿔, 잡음 많은 기록에서 활성 핵심 관심을 융합·추출하는 방법을 제안했어요. 향후에는 온라인 A/B 테스트와, 클릭·즐겨찾기 같은 여러 행동 유형을 함께 쓰는 연구를 하겠다고 해요.
